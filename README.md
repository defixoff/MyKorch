# Мой корч

Устанавливаемый PWA-калькулятор майнинга: риги, видеокарты, прибыль за 24 часа и глобальный тариф электричества. Данные хранятся локально в SQLite.

## Запуск

1. Откройте PowerShell в этой папке.
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте его: `.\.venv\Scripts\Activate.ps1`
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите сервер: `uvicorn backend.main:app --reload`
6. Откройте в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000).

Создайте аккаунт — ему автоматически будет добавлен первый пустой риг. Через браузерное меню можно установить приложение на рабочий стол или экран телефона.

## Вход с телефона в домашней сети

Узнайте IPv4-адрес компьютера командой `ipconfig` и запустите API на всех сетевых интерфейсах:

```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

На телефоне откройте `http://IP_КОМПЬЮТЕРА:8000`. Телефон и компьютер должны быть в одной Wi-Fi сети, а Windows Firewall должен разрешать входящие подключения Python на TCP-порт 8000. Если фронтенд запущен отдельно через Live Server, приложение автоматически направит API на `http://IP_КОМПЬЮТЕРА:8000/api`; для другого API-адреса можно открыть страницу с параметром `?api=http://IP_КОМПЬЮТЕРА:ПОРТ/api`.

## Формулы

- Общий хэш: `хэш на одну карту × количество`.
- Общая мощность: `мощность на одну карту × количество`.
- Грязный доход: `общий хэш × добыча монеты на 1 MH/s × курс монеты`.
- Розетка: `(общая мощность / 1000) × 24 × тариф`.
- Чистый профит: `грязный доход − розетка`.

По умолчанию добыча QTC повторяет исходную Excel-таблицу: `2.8 / 3620 = 0.000773480663 QTC/MH/s в сутки`; курс QTC задан как `$0.39` и редактируется в настройках.

## Публикация в интернете

Для постоянного внешнего доступа нужен сервер с публичным IP/доменом. В репозитории уже есть `Dockerfile` и `docker-compose.yml`, база подключена отдельным Docker volume.

На VPS с установленными Docker и Compose выполните:

```bash
git clone <URL-репозитория> korch
cd korch
openssl rand -hex 32
```

Скопируйте получившийся секрет в `KORCH_JWT_SECRET` внутри `docker-compose.yml`, затем запустите:

```bash
docker compose up -d --build
```

Приложение будет доступно на порту `8000`. Для настоящего домена и HTTPS поставьте перед контейнером Caddy/Nginx и проксируйте домен на `127.0.0.1:8000`; HTTPS обязателен для установки PWA и безопасной передачи токенов. Не публикуйте порт SQLite или сам файл базы наружу. Для Render/Railway выбирайте постоянный диск/volume, иначе SQLite-данные могут исчезнуть при пересоздании контейнера.
