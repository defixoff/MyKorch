# Мой корч — Премиальный калькулятор майнинг-фермы

Личный PWA-калькулятор майнинг-фермы. Считает добычу, расходы на свет и чистый профит по каждому ригу и каждой отдельной видеокарте с учётом сменного графика работы (рабочие/выходные сутки). Устанавливается на телефон и десктоп, работает оффлайн благодаря Service Worker.

**Стек:** FastAPI · PostgreSQL / SQLite · vanilla JS · Tailwind (CDN) · Liquid Glass UI · PWA.

---

## Что нового (NextGen Upgrade)

- ⚡ **Динамические главные показатели по выбранному ригу:** при переключении ригов верхние главные карточки мгновенно пересчитывают и плавно анимируют чистый профит, расходы на свет, грязный доход и маржинальность именно для активного рига (с возможностью переключения на сводку всей фермы).
- 🎮 **Расчёт примерного дохода для каждой видеокарты:**
  - Чистый доход ($ / сут или за выбранный период) с цветной подсветкой маржинальности.
  - Расчёт дохода на 1 штуку при группе видеокарт (`quantity > 1`).
  - Грязный доход ($ и монеты), расход на розетку ($ и Вт), хешрейт и доля в риге.
  - Энергоэффективность карты: `Вт / (MH/s)`.
- 🕒 **Интерактивный переключатель горизонтов времени:** 24 часа, 7 дней, 30 дней и 1 год с плавной числовой интерполяцией (Spring Tween).
- ✨ **Богатые и плавные анимации:**
  - Фоновый кибер-холст с анимированными дрейфующими частицами и паутиной соединений.
  - Одометр чисел: цифры плавно «подъезжают» к новым значениям при любых изменениях.
  - Dynamic Color Bloom: вспышки зелёного/изумрудного ореола при росте профита и розового при убытке.
  - Праздничный салют конфетти при создании ригов, добавлении видеокарт и профитных событиях.
  - Живые пульсирующие индикаторы статуса майнинга (Mining LED).
  - Жидкая скользящая пилюля табов ригов с физикой пружин.
  - Интерактивный 3D-тилт и динамический световой блик за курсором (Pointer Glow).
- 🐛 **Исправления и безопасность:**
  - Исправлен каскадный onDelete в SQLite (`PRAGMA foreign_keys = ON;` на всех коннектах).
  - Исправлена привязка шрифта `@font-face` Unbounded.
  - Исправлена адресация API на относительный путь для работы в любых окружениях, прокси и портах.
  - Исправлено редактирование видеокарт через строгий `data-card-id` вместо хрупких регулярных выражений.
  - Оптимизированы модальные окна настроек монет и смены паролей.

## Возможности

- 👤 Личные аккаунты с PBKDF2-SHA256 (210 000 итераций) и JWT (HS256, TTL 14 дней).
- 🖥️ Неограниченное число ригов на аккаунт, переименование и конфигурация в один клик.
- 🎛️ Конфигурация рига: монета, суточная добыча, тариф за кВт·ч, рабочие/выходные смены, режим расчёта.
- 🪙 Справочник монет с курсом в USD и автоматическим обновлением во всех ригах.
- 📊 Аналитика по ферме, ригам и каждой видеокарте.
- ⚡ Optimistic UI — все правки видны мгновенно, фоновая сверка с сервером.
- 🌗 Тёмная (Obsidian Neon) и светлая (Frost Crystal) темы оформления.
- 📴 Оффлайн-кэш последнего состояния (localStorage + Cache Storage + PWA).

## Запуск

### Песочница: локально / в локальной сети, **без Postgres** (SQLite)

```bash
# Windows:
start-lan.bat

# Linux / macOS:
bash start-lan.sh
```

Скрипт автоматически создаёт окружение, ставит зависимости и запускает сервер на `0.0.0.0:8000` с локальной базой `korch-local.db`.

### Классический запуск (PostgreSQL / Docker)

```bash
docker compose up -d
# или напрямую через uvicorn
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

## Формулы

- `total_hashrate = Σ (hashrate × quantity)`
- `total_power    = Σ (power × quantity)`
- `income_per_mhs = avg_daily_yield ÷ total_hashrate`
- `card_profit    = (card_hashrate × income_per_mhs × price) − (card_power / 1000 × 24 × tariff)`
- `rig_gross      = avg_daily_yield × coin_price`
- `rig_electric   = total_power / 1000 × 24 × tariff`
- `rig_profit     = rig_gross − rig_electric`
